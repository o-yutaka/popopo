# Three-minute video recording

Use the dedicated page, not the general product page:

- Public target: `https://o-yutaka.github.io/popopo/video.html?autoplay=1`
- Local: `python -m http.server 8000` then open `http://localhost:8000/video.html?autoplay=1`

The page contains eight scenes totaling exactly **180 seconds**:

| Time | Scene | What to say |
|---|---|---|
| 0:00–0:15 | Problem | People live through difficult moments inside digital environments, while Scripture remains in another app. |
| 0:15–0:35 | Reveal | Scripture Everywhere AI is one shared context engine for every digital frontier. |
| 0:35–1:20 | Runner story | Explain heart rate, effort, safe timing, the quiet haptic cue, and the Scripture card. |
| 1:20–2:00 | Technical proof | Name the four stages: Context, Gloo AI Studio, YouVersion Platform, Delivery Policy. |
| 2:00–2:25 | Safety | Consent, crisis routing, no public auto-posting, no diagnosis or divine certainty. |
| 2:25–2:45 | Scale | Briefly reveal Gaming, IDE, Social, and Creator as connectors to the same brain. |
| 2:45–2:55 | Working proof | Show FastAPI, typed contracts, tests, CI, public notebook, and source. |
| 2:55–3:00 | Close | “The right word, inside the moment.” |

## Recording controls

- `Space`: play or pause
- `Left/Right`: move between scenes
- `R`: restart
- `?autoplay=1`: begin automatically

## Capture checklist

- Record at 1920×1080.
- Hide browser bookmarks and personal tabs.
- Use 125% browser zoom only if text is difficult to read.
- Keep the final upload at 3:00 or shorter.
- Add captions; the page text is already aligned to the narration.
- Do not claim live API success until `evidence/live-api-evidence.json` exists.
- In the technical proof scene, briefly show the repository and live evidence file when available.
